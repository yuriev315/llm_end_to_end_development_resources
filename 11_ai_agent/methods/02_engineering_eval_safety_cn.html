方法：工程、评测、安全

模型接口

本套件默认 OpenAI 兼容 HTTP（llama-server /v1/chat/completions 与 /v1/embeddings）。
Ollama 安装包未作为主后端（拉模型走其注册表，离线不闭环）。vLLM 未打包（GPU 服务端，体积与 CUDA 依赖超出 CPU 基线）。

连接成功只说明 HTTP 与 API 形状。下列能力必须分别验证：工具调用、JSON schema、并行工具、停止词、视觉。本轮全部为“未验证”。

MCP 与工具协议

MCP 2026-07-28 起改为更无状态：按请求携带协议版本，列表接口不再随连接变化。旧教程里的 session header 可能已经过时。以规范 tarball 为准。

重试、超时、持久化、人工介入、日志

建议最小集合（A01 日志字段已按此留空位）：step、tool、latency、error_class、tokens_est、approval。
重试要对工具做分类：超时可重试，确认类副作用不可盲目重试。
人工介入：执行写文件、下单、发浏览器表单之前停。本轮代码只在注释和配置里体现，没有实测 HITL。

评测指标

指标定义本轮
任务成功率环境判定或测试通过未测
工具正确性名称+参数相对金标未测
成本token × 单价或本地秒数未测
延迟端到端与每步未测

GAIA / SWE-bench / τ-bench 全量数据或运行镜像未当作已备齐。

安全

提示注入分直接与间接。工具返回值默认不可信。权限：文件系统沙箱、浏览器域名白名单、无任意 shell。
AgentHarm、AgentDojo 仅作论文与评测框架源码；本库不提供攻击操作步骤。
