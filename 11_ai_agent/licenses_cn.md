# 许可与再分发

| 类别 | 处理 |
|---|---|
| arXiv PDF | 作者预印本；再分发遵循 arXiv 非独占许可与各文声明。公开增量包装入 [`_public/papers/agent`](../_public/papers/agent/) |
| LangGraph / Agents SDK / CrewAI 源码 | MIT（以 tarball 内 LICENSE 为准） |
| AG2 | 以仓库 LICENSE 为准，文档可能为 CC-BY-4.0 |
| Qwen2.5 GGUF 0.5B–7B | Apache-2.0（官方 Hugging Face 卡）；**本库只记 URL，不保存权重文件** |
| BGE 嵌入 / reranker | MIT；**权重只记 URL**；tokenizer/config 已保存 |
| llama.cpp 二进制 | MIT + 依赖通告，见归档内文件 |
| Node.js | Node.js 许可 |
| Playwright Chromium | 跟随 Playwright / Chromium 许可；体积大，公开与否见增量包清单 |
| 历史 AutoGen 0.2 | MIT；归档项目 |
| 付费课、非 OA 期刊 PDF | **不下**。只在 missing 中列书目 |
| Llama / Gemma 等需额外同意的权重 | **未选作默认可公开模型** |

不可再分发的内容若误入，应立刻挪到 `_local_only/ai/agent/` 且不打公开 tar。
