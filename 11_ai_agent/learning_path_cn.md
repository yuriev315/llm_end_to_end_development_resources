# 中文学习路线

先修：Python 函数与 JSON、HTTP 基础、概率直观（不必先学强化学习）。不必先训 LLM。

## 阶段 0 — 分清三件事

1. **语言模型**：补全文本。  
2. **工具循环**：模型输出被解析成调用，环境返回观察，再进入下一步。  
3. **产品化 Agent**：超时、重试、权限、日志、预算、人工确认。

只装 SDK 会停在第 1 层。本专题强制经过第 2、3 层。

## 阶段 1 — 单步工具与结构化输出（约 1–2 天）

读 [`theory/01_mechanisms_cn.md`](theory/01_mechanisms_cn.md) 前半。对照 ReAct 论文（2210.03629）看“思考 / 行动 / 观察”。  
实践：运行套件 **A01** 的 mock 路径（本轮未跑；你本地可跑 mock，不需要模型）。  
目标：自己能画出一步工具调用的 JSON schema，并说出小模型为什么会在这里失败。

## 阶段 2 — 多步任务、规划、反思（约 2–3 天）

论文：Tree of Thoughts、Reflexion、ReWOO、CoALA。  
要点：规划可以在语言模型里，也可以在图/状态机里（LangGraph 的价值在此）。  
实践：仍用 A01，把步数上限、超时、错误写进日志。不要一失败就“再问一次模型”而不记账。

## 阶段 3 — RAG 与记忆（约 2–4 天）

论文：Lewis RAG、Gao 综述、Self-RAG、MemGPT。  
实践：**A02**。先用 hash 嵌入看清切块 / 检索 / 引用流水线，再换 bge 与 llama-server 嵌入。  
记住：hash 命中不是语义检索；嵌入模型可用也不等于生成模型能按引用作答。

## 阶段 4 — 工程协议（约 2 天）

读 MCP 规范 2026-07-28 与 [`framework_compare_cn.md`](framework_compare_cn.md)。  
内容：重试、幂等、持久化 checkpoint、人工介入、追踪。LangSmith 等云追踪**未**打包进离线套件。

## 阶段 5 — 编码、浏览器、多 Agent（约 1 周）

- 编码与文件：**A03**（沙箱）+ aider 源码（不要对真实仓库放开 shell）。  
- 浏览器：**A04** 只打本地 HTML；外网站点另谈权限。  
- 多 Agent：**A05** mock 角色流 → 再选 AG2 或 CrewAI，二者不要混装。

## 阶段 6 — 评测与安全（持续）

指标：任务成功率、工具参数正确率、成本、延迟、人类介入次数。  
安全：间接提示注入、工具权限、沙箱。读 AgentDojo、Greshake、AgentHarm 时当作**评测与防护**文献，不要在本库里复现攻击载荷。

## 三条轨道

| 轨道 | 顺序 |
|---|---|

| 应用 | A03 或 A04 或 A05 三选一做深，不要并行堆框架 |
